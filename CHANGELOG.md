## [1.00] - 2026-11-21
First release.

### Added
- **One list** of what starts with Windows: Run entries for you and for all users (64-bit and 32-bit),
  the two Startup folders, and scheduled tasks that run at sign-in or start-up (not Windows' own),
  with each program's name, publisher, source and command.
- **Turn off / Turn on** through Windows' StartupApproved settings, as Task Manager does: nothing is
  deleted, and everything can be turned on again. All-users items and tasks ask for administrator
  rights.
- **Think twice**: security software and device drivers are marked and confirmed before turning off;
  entries whose program is missing are marked in red.
- Search, Open file location, Refresh (F5), light, dark and auto looks, Help and an About box.
  Listed in the Home Launcher's Utilities tab.
